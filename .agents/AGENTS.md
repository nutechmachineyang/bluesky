# Workspace Rules for Antigravity AI

이 워크스페이스에서 작업을 진행할 때 아래 규칙을 반드시 준수해야 합니다.

## 📌 문서 자동 업데이트 규칙 (Mandatory Documentation Updates)

1. **변경 사항 실시간 기록**:
   * 프로젝트의 소스 코드를 변경(추가, 수정, 삭제)하거나 설정을 변경하는 작업을 완수한 경우, 작업 내용을 반드시 **[문제 보고서 및 변경 이력](file:///c:/Users/nutec/OneDrive/Desktop/harryyang/doc/issues.md)**(`doc/issues.md`)의 **Changelog** 섹션에 날짜와 함께 기록해야 합니다.

2. **구조적 변경 시 매뉴얼 업데이트**:
   * 디렉토리 구조가 바뀌거나 새로운 페이지 섹션/블록을 추가/제거한 경우, 혹은 로컬 실행 방법 등이 변경된 경우에는 반드시 **[제작 매뉴얼](file:///c:/Users/nutec/OneDrive/Desktop/harryyang/doc/manual.md)**(`doc/manual.md`)의 해당 세부 항목을 업데이트해야 합니다.

3. **이슈 발견 시 기록**:
   * 작업 도중 발견된 버그, 문제점, 보안 취약점, 혹은 미구현 항목(예: 백엔드 미연동 등)이 있다면 즉시 `doc/issues.md` 파일의 **주요 이슈 및 해결 가이드** 섹션에 추가하고 해결 방안을 함께 서술해야 합니다.
